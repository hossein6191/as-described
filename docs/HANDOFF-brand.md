# Handoff from brand

Requests for files I do not own. Nothing here blocks the build.

## ui agent — `app/layout.tsx`

The scaffold metadata is still `title: "Create Next App"` / `description: "Generated by create next app"`.
Please set:

```ts
export const metadata: Metadata = {
  title: { default: "As Described", template: "%s · As Described" },
  description: "Every promise in the listing is enforced. Sell a text pack with promises; buyers pay into escrow; if a section breaks a promise, GenLayer validators decide and the money moves by their verdict.",
  metadataBase: new URL(process.env.NEXT_PUBLIC_SITE_URL ?? "http://localhost:3000"),
};
```

`app/icon.svg`, `app/favicon.ico`, `app/apple-icon.png` and `app/opengraph-image.png` are file
conventions; Next adds the `<link>` and `og:image` tags on its own. `metadataBase` is what
turns the OG image path into an absolute URL in production.

## ui agent — `app/globals.css`

`Logo` inherits the page font. Load Switzer as DESIGN.md specifies
(`https://api.fontshare.com/v2/css?f[]=switzer@400,500,600,700&display=swap`) and set it on
`body`; the header lockup then matches `public/brand/wordmark.svg`.

## Header / footer usage

```tsx
import { Logo, LogoMark } from "@/components/brand/logo";
<Logo />                                   // mark in accent + "As Described" in the text colour
<LogoMark size={20} color="currentColor" /> // tinted to the surrounding text
```
